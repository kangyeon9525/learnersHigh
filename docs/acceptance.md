## 1. 공통 완료 기준 (모든 작업 공통)

- [ ]  **TypeScript 오류 0** — 컴파일 에러/경고 없음, 신규 코드 미해결 `any` 없음(임시 `any`는 TODO + 백로그).
- [ ]  **규칙 준수** — `architecture.md`의 계층/네이밍/통신/상태관리/디자인 규칙 위반 없음.
- [ ]  **제약조건 검증** — 비즈니스 로직(점수·판정·성장 단계·종료 정산 집계)은 **백엔드에서만** 수행. 프론트는 표시만. 도메인 타입은 `shared/types` 사용, Mongoose 스키마와 일치.
- [ ]  **집중 보호** — 학습 진행 중에는 성취/목표 달성 알림·모달이 노출되지 않고, 달성 안내는 **학습 종료 후 정산 모달**로만 일괄 노출.
- [ ]  **실 DB 영속성** — 상태 변경이 MongoDB에 저장되고 서버 재기동 후에도 유지. 누적/동시 갱신은 원자적 연산(`$inc`/`findOneAndUpdate`)·트랜잭션으로 무결.
- [ ]  **실제 응답** — API는 시딩 더미라도 **실제 DB 상태에 근거**해 응답하고, 성공/검증오류 상태 코드를 실제 결과에 맞게 반환. 정산 응답(`StudySessionResult`)은 저장된 DB 상태 기준으로 조립.
- [ ]  **공용 컴포넌트 → Storybook** — 새/수정 공용 컴포넌트는 Storybook에서 default/loading/error/empty 및 주요 변형 확인 가능.
- [ ]  **핵심 흐름 → Playwright** — 관련 핵심 플로우 E2E(루트 `e2e/`)가 시딩 데이터 기반으로 통과.
- [ ]  **상태 UI** — 로딩/에러/빈 상태가 정의·동작.

## 2. 기능별 완료 기준

### 2.1 인증 / 입퇴실 (출입·계획)

- [ ]  (시딩 사용자 기반) 사용자 식별/세션이 `userId`로 일관 유지.
- [ ]  입실 시 타이머 가동 가능, 입실 상태가 DB에 기록.
- [ ]  퇴실 시 **목적 필수 선택**, 귀가 처리 시 리포트 발송(모의) 트리거.
- [ ]  캘린더 계획 CRUD 및 드래그앤드롭 이동 동작.

### 2.2 대시보드 (홈)

- [ ]  진입 시 현재 학습 상태·당일 계획·성장 위젯(나무/화분) 요약을 한 화면에 표시.
- [ ]  위젯 값이 DB 응답 기준으로 동기화되고 새로고침 후에도 일치.
- [ ]  성장 위젯에서 성장 통합 대시보드로 진입 가능.
- [ ]  태블릿 가로 레이아웃에서 깨짐 없음(Figma 디자인 일치).

### 2.3 모니터링 (타이머 / 시딩 AI 감지)

- [ ]  스톱워치/타이머 모드 제공 및 정확한 시간 계측.
- [ ]  `mock-ai`가 시딩된 집중/이탈 시나리오를 일정 주기(예 30초) 재생·주입.
- [ ]  비정상(이탈) 상태 시 **비차단 인라인 경고**(`AlertBanner`) 노출. 타이머는 계속 진행하며 **집중 시간만 미적립**.
- [ ]  학습 진행 중에는 집중/이탈 경고 외 **성취/목표 달성 알림이 노출되지 않음**(집중 보호).
- [ ]  감지 결과가 `aiEvents`(시각·상태)로만 기록되고 원천 데이터 미저장.

### 2.4 학습 성취 (Milestone)

- [ ]  학습 종료 시 백엔드에서 성취 조건(`conditionCode`) 충족 판정.
- [ ]  학습 진행 중에는 성취 알림 미노출. 충족 시 성취 인증 부여 + 점수 지급이 **학습 종료 정산 모달**에서 일괄 노출.
- [ ]  `isAchieved`/`achievedAt`가 `milestones` 컬렉션에 정확히 반영.

### 2.5 학습 목표 (Goal)

- [ ]  일/주/월 목표 자동 배정, `targetValue`/`currentValue` 관리.
- [ ]  학습 종료/주기 종료 시 백엔드 달성 판정 + 차등 점수, `isCompleted` 갱신.
- [ ]  완료된 퀘스트가 **학습 종료 정산 모달**에서 일괄 노출(학습 중 미노출).

### 2.6 성장 시스템 (누적 나무 / 월간 화분 / 통합 대시보드)

- [ ]  점수 1회 획득이 **누적 나무·월간 화분 양쪽에 동시 반영**(원자적 갱신).
- [ ]  누적 나무: 영구 누적, `lifetime.currentStage` 상승(씨앗→새싹→묘목→성목) 일러스트 전환.
- [ ]  월간 화분: 매월 초기화, 당월 점수만 반영, 월말 고정(개화) 후 `archive` 이관.
- [ ]  **성장 통합 대시보드**에서 중심 누적 나무 + 주변 월간 화분이 **한 화면 전체 그림**으로 표현.
- [ ]  통합 대시보드에서 누적/월간 **캘린더 뷰로 드릴다운**하여 날짜별 성장 단계·달성 내역 조회 가능.

### 2.7 평가 / 리포트

- [ ]  종료 시 진척도·만족도 5점 척도 입력·저장.
- [ ]  일간 리포트(타임라인/코멘트), 월간 리포트(효율 차트/과목별 추이) 렌더.
- [ ]  통계 API가 MongoDB **aggregation 파이프라인**으로 기간 집계(순공 효율·가상 순위) 계산.

### 2.8 라이브러리 / 코칭 (부가)

- [ ]  학습/수업/생활 카테고리 필터링 동작.
- [ ]  코칭 클래스 가상 예약 팝업 + QR/Link 다이렉트 접속(모의) 동작.

### 2.9 학습 종료 정산 모달 (Session Result)

- [ ]  학습 진행 중에는 동기 부여 알림이 노출되지 않음.
- [ ]  학습 종료 시 이번 세션의 **신규 성취·완료 퀘스트·획득 점수·성장 단계 상승**을 하나의 모달로 일괄 노출.
- [ ]  모달 데이터는 종료 응답에 포함된 `StudySessionResult`(저장 컬렉션 아님)를 사용하고, 서버 확정 결과만 표시(낙관적 미적용).
- [ ]  획득 항목이 없는 경우(빈 결과)에도 모달/상태가 자연스럽게 처리.
- [ ]  모달에서 성장 통합 대시보드/마이페이지 보관함으로 이동 가능.

### 2.10 마이페이지 성취·성장 보관함 (Collection)

- [ ]  획득 성취(업적)를 달성/미달성 구분 그리드로 표시.
- [ ]  완료한 퀘스트 이력과 성장 단계 변화를 조회 가능.
- [ ]  특정 성취/퀘스트 선택 시 달성 일자·획득 점수 등 상세 조회.
- [ ]  보관함에서 성장 통합 대시보드/상세 캘린더로 진입 가능.
