# Acceptance Criteria

> 기능·플로우별 수용 기준 및 E2E 검증 체크리스트를 기록하는 문서입니다.

## 전역 원칙

- [ ] 학습 진행 중 성취·퀘스트·성장 알림/모달이 **노출되지 않는다**
- [ ] 학습 종료 시에만 `StudySessionResult` 기반 **종료 정산 모달**이 노출된다
- [ ] 성취·목표 판정·점수·성장 단계는 **백엔드에서만** 처리된다
- [ ] FE/BE 타입은 `@learners-high/shared` 단일 소스를 사용한다

## Flow 1: 학습 → 종료 정산 → 성장

- [ ] 입실 후 타이머 시작 가능
- [ ] 학습 중 집중/이탈 경고만 표시 (비차단 인라인 경고 — 타이머는 계속 진행, 이탈 중에는 집중 시간 미적립)
- [ ] 종료 시 만족도(1–5) 입력 후 세션 API 전송
- [ ] 정산 모달에 신규 성취·완료 퀘스트·획득 점수·성장 단계 변동 표시
- [ ] MongoDB에 점수·세션·성장 상태 반영
- [ ] 모달에서 성장 대시보드로 이동 가능

## Flow 2: 성장 통합 대시보드

- [ ] 정원 풍경 UI — 중앙 누적 나무 + 주변 월간 화분
- [ ] 성장 단계가 점수에 따라 시각적으로 구분됨

## Flow 3: 마이페이지 보관함

- [ ] 성취 그리드 (달성/미달성)
- [ ] 퀘스트 이력 목록
- [ ] 성장 대시보드 진입 링크

## E2E (`e2e/tests/`)

- [ ] `study-flow.spec.ts` — 학습 시작·종료·정산 모달
- [ ] 성장 대시보드 조회

## 비기능

- [ ] 태블릿 가로(1280×800) 레이아웃 대응
- [ ] API 실패 시 FE 에러 안내
- [ ] 종료 정산 모달은 백엔드 확정 결과만 표시
